# Code of Conduct

We want TANGLAW's contributor community to be welcoming and respectful.

Please contribute with patience, respect and constructive technical feedback. Harassment, hateful speech, personal attacks, intimidation and disclosure of another person's private information are not acceptable.

Maintainers may hide or remove harmful content and limit participation when necessary. Report concerns privately to the repository maintainer via their GitHub profile, including the relevant issue or pull request and enough context to assess it. Do not publish sensitive information.

This policy applies to repository discussions, issues, pull requests and project-related community spaces.
